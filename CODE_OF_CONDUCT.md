# Code of Conduct

## Purpose

Sanabot Skills is a public, developer-facing repository for Sanafi's agent-skill packs, plugin metadata, and install documentation.
We want collaboration here to be direct, technically rigorous, and respectful.

This code of conduct applies anywhere people participate around this project, including:

- This GitHub repository
- Issues, pull requests, reviews, and discussions
- Linked support spaces such as the Sanafi Discord's `#sanabot-mcp` channel
- Other project spaces where someone is representing this repository or the Sanabot Skills community

## Expected behavior

Participants are expected to:

- Be respectful in disagreement and critique ideas, code, and documentation without attacking people
- Keep feedback concrete, evidence-based, and relevant to the technical problem being discussed
- Assume good intent first, then ask clarifying questions before escalating
- Respect privacy and security boundaries, including Sanafi API keys, user data, and unpublished operational details
- Stay on topic in public threads and avoid derailing contribution, support, or review discussions
- Accept correction gracefully and help keep the repo welcoming for contributors with different backgrounds and experience levels

## Unacceptable behavior

The following behavior is not acceptable:

- Harassment, intimidation, stalking, threats, or sustained personal attacks
- Discriminatory or degrading language related to race, ethnicity, nationality, religion, gender, gender identity, sexual orientation, disability, age, or similar protected characteristics
- Sexualized language, unwanted sexual attention, or sharing sexual content in project spaces
- Doxxing, sharing private correspondence without permission, or exposing confidential information
- Posting API keys, credentials, personal financial information, or other sensitive data in public threads
- Trolling, baiting, bad-faith arguing, spam, impersonation, or deliberately disruptive behavior
- Encouraging unsafe use of the product, misuse of scopes, or attempts to bypass documented security or privacy limits

## Maintainer responsibilities

Project maintainers may moderate discussions, edit or remove inappropriate content, close or lock threads, reject contributions, or restrict participation when needed to protect the project and its contributors.

Moderation decisions will be made based on the severity, context, and pattern of behavior, with the goal of restoring a productive working environment.

## Reporting

If you experience or witness behavior that violates this code of conduct, email `jume@sanafi.xyz` with:

- A short description of what happened
- Links or screenshots if available
- The relevant usernames and dates
- Any context that would help us review the report fairly

We will review reports as promptly and discreetly as we can.

For security vulnerabilities, do not use public issues or pull requests. Follow the disclosure process in [SECURITY.md](SECURITY.md).

## Enforcement

Possible responses include:

- A private warning or request to change behavior
- Removal of comments, issues, pull requests, or other content
- Temporary suspension from project spaces
- Permanent ban from participation in this project's community spaces

People asked to stop unacceptable behavior are expected to comply immediately.
